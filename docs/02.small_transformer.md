# 小型 Transformer 序列表征增强树模型：首篇期刊论文规划、补充实验与相关工作

检索截止：2026 年 10 月 24 日。本文是研究规划与公开文献查新，不是已完成论文，也不是正式科技查新机构出具的查新报告。所有预期增益均须实验验证。

## 1. 建议先收敛成什么工作

建议首篇围绕一个具体问题：

> 在强人工特征和严格时间外评估下，总参数不超过约 300 万的小型 Transformer，能否利用无标签历史事件学习到可被 XGBoost 使用的额外信息？哪些表征输出有效，收益来自哪里，计算成本是多少？

推荐暂定题目：

**中文：面向强表格基线的轻量级自监督序列表征：增量价值与计算成本研究**

**英文：Compact Self-Supervised Sequence Representations for Augmenting Strong Tabular Baselines: Incremental Value and Computational Cost**

如果最终具有稳定正向结果，可以改为更明确的应用题目：

**Compact Transformer Representations for Enhancing Gradient-Boosted Fraud Detection**

如果结果以边界和负结果为主，使用中性题目：

**When Do Compact Sequence Representations Add Value to Strong Tabular Models? An Empirical Study on Rare-Event Detection**

这是计算机方向的表征学习、机器学习与应用研究。金融是验证场景，不需要写成金融经济学论文。全文应突出可泛化的方法、评估协议、信息增量和效率，业务描述只用于说明任务与约束。

**第一篇无需追求基础模型、通用智能或巨大参数规模。** 但“真实数据＋Transformer＋XGBoost”本身已经不是创新点，仍需要一个明确、完整、可验证的研究结论。

## 2. PANTHER 发在哪里，如何理解级别

PANTHER 已收入 **NeurIPS 2025 Main Conference Track**，官方论文集为 *Advances in Neural Information Processing Systems 38*。[R1]

它是会议论文，不是期刊论文；NeurIPS 是机器学习领域顶级会议，CCF 官方目录将其列在人工智能 A 类会议下。[S1] 计算机领域的顶会承担重要成果发表功能，不能用“会议低于期刊”来理解。

NeurIPS 的 A 类与期刊 JCR 分区、中科院分区不是同一体系。本文不把这些体系混用，也不把单篇论文质量与 venue 等级画等号。

对首篇而言，不必照搬 PANTHER 的数据、模型和部署规模。更可行的是采用小模型，完成可信的正向或边界性证据，再根据结果选择合适期刊。

### 3.3 需要修正的选题判断

此前讨论的“为什么预训练变好而下游不变好”仍有价值，但 **TCT 已报告相近现象，CoLES 也讨论过自监督任务表现与下游表现不完全一致**。[R3][R9]

因此，首篇应进一步提供下面至少一类新证据：

1. 在相同小模型、相同数据与预算下，找到一种更有效的输出或训练方式，并解释原因。
2. 用多个时间切分、两类数据及系统对照，明确哪些条件决定增量，而非仅报告一次成功或失败。
3. 得到可复用的效率结论：在有限参数、历史长度、表示维数下，哪些方案处于收益与成本的较优位置。

“残差式自监督预测＋强基线下的事件级评估”可作为待验证的研究路线，但本轮检索不能证明该组合全球首次出现。投稿前还需围绕最终保留的算法作精确检索。

## 4. 从原理说明：为什么小型 Transformer 也可能有帮助

### 4.1 两个模型处理的是不同输入形态

设当前时刻为 t：

- H_t：当前之前的历史事件序列；
- x_t：当前已可见的事件字段；
- F_t：现有人工特征；
- y_t：下游二分类标签；
- z_t = Encoder(H_t)：学习到的历史表示。

原模型预测 `g(F_t)`；增强模型预测 `g(F_t, z_t)`。这里 Transformer 本身也是机器学习模型；研究问题是“自动表征与人工特征怎样互补”。

如果人工特征只保留计数、均值和最近一次状态，不同事件顺序可能得到相同 F_t。序列模型可能保留“先出现什么、随后出现什么、间隔如何变化、哪些字段共同变化”。小模型只要能表达任务需要的这些模式，就可能有效，不要求具备语言知识或数十亿参数。

例如，两段历史包含相同次数的 A、B 事件，但分别是 `A,A,B,B` 与 `A,B,A,B`。计数相同，交替规律不同。如果这种差别与标签有关且人工特征未编码，序列表征才有机会补充信号。这个例子说明可能性，不代表真实数据一定遵循该规律。

### 4.2 更精确的必要条件

在理想的总体分布和无限制预测器下，最优对数损失减少量满足：

`L*(F) - L*(F,Z) = I(Y; Z | F)`。

也就是说，Z 必须在已知 F 后仍携带与 Y 有关的信息，才有理论上的增益空间。这是条件熵恒等式，不是本文新定理。

但实际使用有限样本与有限容量 XGBoost，增加 Z 也可能只是在让已有信息更容易被树利用；所以不能把观察到的 AP 增益直接称为测得了条件互信息。反过来，理论上有额外信息也不保证有限模型能利用它。

下一事件预训练优化的是行为目标 U，而非标签 Y。提高对 U 的预测，不保证增加 `I(Y; Z | F)`，更不保证 AP 上升。AP 是排序指标，上述对数损失恒等式不能作为 AP 提升定理。

### 4.3 为什么只用几个 surprise 可能不够

surprise 将一个分布压为当前观测值的 NLL。不同历史可能得到相同 NLL，却对应不同状态；对多个字段各自预测，也未必保留字段组合关系。embedding 可以保留更多上下文，但也可能带来无关维度。

因此首篇重点比较三个输出接口：历史 embedding、逐头 surprise、二者组合。所有输出来自同一个模型，才能把“训练模型不同”与“输出压缩不同”分开。

### 4.4 为什么不能只靠理论直觉发表

上述机制能解释方法动机，却不足以证明本数据上的实际价值。必须用移除时间编码、改变历史长度、简单统计与 GRU 对照等实验检验。Attention 图或二维可视化可以展示现象，但不能单独证明模型学到因果机制或额外信号。

## 5. 推荐的方法范围：一个主方案，一个有上限的增强方案

### 5.1 主方案：紧凑历史编码器，直接保留表示

首轮沿用已有七头预测设置，先固定分桶和字段，避免同时改变所有因素。输入只包括预测时可见的历史：

1. 类别字段用小维度 embedding，数值字段做稳定变换并带缺失标记。
2. 一个事件映射成一个向量，不转成自然语言文本。
3. 加事件顺序编码、真实时间间隔及必要周期信息。
4. 使用 2 层 Transformer，取最后一个有效历史位置的隐状态。
5. 经训练中的投影层得到 32 维 z，七个预测头从 z 输出，因此该瓶颈实际参与学习。
6. 冻结 encoder 后，导出逐事件 z、逐头 NLL，分别或合并进入 XGBoost。

这样先回答“目前少量 surprise 是否损失了可用信息”。它是可靠基线与系统研究主干，**不是凭这些组件就有了新算法**。

### 5.2 增强候选：以简单个人模型为起点的残差预测

动机：当前简单个人模型在部分目标上已经很强。让小 Transformer 主要学习其未解释的部分，可能更节约容量。为避免混淆，不用下游标签来构造这一预训练目标。

设 q_j(k | H_t) 是第 j 个字段的简单历史预测概率；r_j(k | z_t) 是 Transformer 的修正值：

`p_j(k | H_t) = softmax_k(log(max(q_j(k | H_t), eps)) + r_j(k | z_t))`。

最小化真实下一事件的多头交叉熵，可加小的修正值正则。q 的全局参数只在允许的历史期拟合，个人状态逐事件先查询后更新；q 不通过神经网络反向训练。

当 r=0 时，模型退回 q；非零修正尝试解释 q 之外的行为结构。注意：这只是优化偏置，不保证表示与人工特征独立，也不保证包含更多与标签有关的信息。

输出可包括：

- 32 维残差模型隐状态；
- 每头 `log p_j(observed) - log q_j(observed)`；
- 与普通预训练保持完全一致的 surprise。

需有三个严格对照：q 本身、同骨干普通预训练、同骨干残差预训练。它们使用相同词表、历史、锚点及训练预算。不能只比较“旧小样本模型”与“新全量模型”。

首轮不要同时加入对比学习、画像、长序列、监督微调和多个新损失。增强候选若没有稳定线索，保留标准主方案并如实转向实证论文。

### 5.3 身份信息放在消融实验，不作为主贡献

默认先不加入巨大的个人 ID 表。以相同主干比较：历史；历史＋小 ID embedding；历史＋长期行为摘要。长期摘要另直接加入 XGBoost 作对照。

身份参数可存储稳定偏好，但不是动态历史检索器。新增身份、新习惯和有限覆盖都可能削弱收益。若实体数量很大，ID 参数可能超过 Transformer 主干，必须计入总参数。

如果只是 ID 提升 NLL、AP 没变，报告这一边界；不要因此把整个首篇扩大成复杂个性化系统。

## 6. 模型与算力预算

建议主配置：

| 项目 | 默认 | 最小规模消融 |
|---|---|---|
| 历史长度 | 32；保留已有 16 作为对照 | 16 / 32 / 64，只在一个固定骨干上比较 |
| Transformer 层数 | 2 | 1 / 2；有收益再考虑 3 |
| 隐藏维数 | 128 | 64 / 128 |
| Attention heads | 4 | 固定即可 |
| FFN 宽度 | 256 | 与模型规模一起明确记录 |
| 输出 embedding | 32 | 16 / 32 / 64，优先复用隐状态做训练期 PCA 对照 |
| 单字段输入维度 | 8–32 | 按词表规模固定 |
| 总参数目标 | 约 100万–300万以内 | 必须包括输入表、输出头、身份表 |

按标准注意力与两层 FFN 估算，一层主干参数约 `4d² + 2d·d_ff`。d=128、d_ff=256 时约 13.1 万，两层约 26.2 万，尚未包括偏置、归一化和其他模块。

真正可能占参数的是大类别表和预测头。示例预算：所有类别词表总项数控制在约 32768，输入维度 32，则输入表约 105 万参数；七头从 32 维瓶颈直接预测，总输出词表规模相当时也约 105 万；加主干和投影后可接近 250 万。此为设计估算，实际必须打印参数清单。不能把骨干 26 万写成整网 26 万。

对象字段可采用训练期 top-K＋UNK，或固定哈希输入；若输出头也采用哈希类别，必须说明它预测的是桶而非精确对象。所有对照使用相同映射，并报告覆盖率及未知比例。

训练策略：

- 一块企业可用 GPU，先做吞吐基准；显存容量与批大小实测，不承诺固定小时数。
- 第一轮用少量月份与明确预算，例如先批准 4–8 GPU 小时作可行性筛查，再依据吞吐和曲线决定是否扩展；这是预算，不是效果保证。
- 按训练步数、处理事件数和总 GPU 小时记账，不机械复制 100 个全量 epoch。
- 序列读取按实体和时间组织，流式读取 Parquet，避免为每个锚点物化一份重复的 32 条历史。
- 限制高频实体支配训练时，需明确锚点采样方法；实体均匀与事件均匀是不同学习分布。
- 固定最终配置后再做多种子，不对所有候选跑完整多种子网格。

只要字段固定，不需要下载任何外部语言模型；核心可用现有 PyTorch、NumPy、Parquet 工具和 XGBoost 实现。CPU 用于数据准备、统计基线和树模型；小 Transformer 的正式训练建议 GPU。

## 7. 论文必须补哪些实验

### 7.1 先修复证据链

已有 Hybrid45/46 只能作为先导实验：输出混合了简单统计模型和 Transformer，第六列也可能解释主要收益。先完成前一份执行信的简单模型归因对照，不能把现有全部提升归于神经网络。

严格的主时间线：`无标签预训练 P → 监督训练 S → 开发验证 V → 最终时间外 T`。P 内可以另划前后段做预训练验证。词表、标准化、PCA 和 q 的全局统计均遵守冻结边界。S 的每条特征来自冻结模型和该事件此前历史。

已有 Test、OOT 已用于观察与选方向，后续使用时称探索性结果。新的确认时间段在固定方法之后打开。数据不足时可做回溯滚动切分，但不能伪称从未接触过的最终测试。

### 7.2 核心比较表：首篇的最低完整版本

F 表示调优后的完整人工特征；C 表示各模型统一使用的历史覆盖、缺失标记。已有同义列直接复用。

| 编号 | 模型 | 必须回答的问题 |
|---|---|---|
| M0 | XGBoost(F,C) | 完整强基线 |
| M1 | XGBoost(F,C,简单统计偏离) | 神经模型是否只复制统计规律 |
| M2 | XGBoost(F,C,普通 Transformer surprise) | 复现少量预测特征路线 |
| M3 | XGBoost(F,C,同模型 32维 embedding) | 输出接口是否造成信息损失 |
| M4 | XGBoost(F,C,embedding,surprise) | 两类输出是否互补 |
| M5 | XGBoost(F,C,GRU 自监督 embedding) | 是否确实需要 Transformer |
| M6 | XGBoost(F,C,CoLES 风格表示) | 与代表性对比预训练方法比较 |
| M7 | XGBoost(F,C,残差预训练输出) | 新训练偏置是否增加实际收益 |

M2–M4 共用一个 encoder，只重训树模型；M7 是增强候选，有线索才扩大。M5 保持相同输入、输出和大致参数/计算预算。CoLES 如果只能做简化实现，必须称“CoLES-style”，公开与原实现的区别，不宣称完整复现。

补一个随机冻结 encoder 的低成本控制，判断收益是否仅来自随机投影/字段变换；有需要时补“仅当前事件编码”的控制，区分时序信息与字段表示。它们作为附录或开发诊断，无需全部升级为大规模主实验。

若篇幅和预算只允许一个外部自监督基线，优先 CoLES；NPPR 对本任务也很接近，应至少解释方法差异，有预算再增加。无需声称复现大型 PANTHER、PRAGMA；没有同条件运行的结果不能放在同一性能排名表。

### 7.3 机制消融：避免组合爆炸

固定一个已选主模型，依次改变一个因素：

| 实验 | 用途 | 优先级 |
|---|---|---|
| embedding vs surprise vs 两者 | 检验压缩与融合接口 | 必做，复用 encoder |
| 完整 F 与预先定义的较弱 F | 区分替代与互补；完整 F 始终为主结果 | 必做，主要增加树训练 |
| 去掉真实时间间隔编码 | 检验时距信息 | 必做，一个额外 encoder |
| 长度 16 / 32 / 64 | 检验历史窗口及成本 | 必做，但不与所有宽度交叉 |
| 普通 vs 残差预测 | 验证增强候选 | 方法型论文必做 |
| GRU vs Transformer | 检验架构必要性 | 必做 |
| ID / 无 ID / 长期摘要 | 个性化机制 | 可选，不阻塞首篇 |
| 监督样本量 25% / 50% / 100% | 标签效率 | 可选，保持采样规则与测试集一致 |
| 缺失事件/字段的扰动 | 鲁棒性 | 后续方向，首篇仅有明确问题时加入 |

顺序扰动必须解释清楚：若同时打乱时间字段与事件配对，会制造无效样本。可比较去掉位置编码或训练一个合理的顺序无关聚合器；测试时打乱顺序只能作为敏感性检查，不能单独证明因果。

### 7.4 数据、重复性和指标

推荐“一份真实工业数据＋一份可公开复现的序列数据”。IBM TabFormer 可用于流程复现和对照，但它是合成数据，不能当成第二份真实工业验证。[R2] 不要把没有可靠实体 ID 的匿名逐行数据强行拼成个人序列。

如果暂时只有私有数据，至少做两个非重叠时间测试段，并公开足够的字段类型、缺失统计、历史长度分布、类别基数、标签定义、采样规则、参数与代码。多时间段仍不是多独立数据源，应在局限性中说明。

主指标固定为 `average_precision_score` 的 AP；另外报告 ROC-AUC、Recall@固定告警比例、训练与推理成本。AP 与梯形 PR-AUC 不混用，不跨不同正例比例的评估集直接比大小。

最终主要对比至少三个训练种子；报告神经预训练种子与 XGBoost 种子。可配对整个流水线种子，而不是只固定一个 encoder、变化树种子后声称覆盖全部随机性。

在相同评估行上做配对日期块 bootstrap，补实体聚类敏感性分析；报告 AP 绝对差、相对差与区间。短测试期不足以支持稳定区间时直说。分组结果至少包括历史不足/充足、对象已见/未知以及时间段。

主实验固定现有监督负采样规则，先隔离表示效应。额外改变负采样量属于独立实验；无标签预训练使用更多正常事件，不能被表述为必然“恢复负采样丢失的一切信息”。

### 7.5 计算成本是论文结果，不只是约束

报告：总参数与各模块参数、预训练 GPU 小时、处理事件数、峰值显存、CPU 特征导出吞吐、XGBoost 训练时间、embedding 存储量和在线推理路径。

32 维 FP32 纯数值表示每事件 128 字节，不含主键、文件格式及索引；是否缓存到实体级、多久更新，会改变成本与语义。单样本模型推理时间不能代替线上端到端时延。

若在线使用异步缓存，需要按真实更新时间在离线模拟同样的陈旧程度。不要离线给每一行提供即时 embedding，线上却用数小时前缓存，再把离线结果直接视为线上收益。

## 8. 推荐的三条贡献表述

结果成立后，优先写成下列形式；括号里的结果必须用实验填入。

1. **受限资源下的表征增强方案。** 在总参数不超过指定预算时，构建可与现有树模型结合的序列表征流程，报告真实数据和公开数据上的效果与计算成本。
2. **输出与训练方式的对照证据。** 控制模型、数据和训练预算，分析 embedding、surprise、简单统计及残差预训练的差别，识别强基线上的实际增量来源。
3. **可信的适用边界。** 在时间外、历史稀疏和未知类别等条件下，给出增益或失效范围，并说明预测损失与 AP 的关系。

如果残差方法稳定优于普通预训练，可把它升为首要方法贡献；若没有，删除“提出有效残差方法”的说法，保留其为诚实的消融结果。

不建议写：首次结合 Transformer 与 XGBoost；首次无标签学习行为；小模型优于所有大模型；无需标签即可识别所有异常；证明预训练必然提升 AP。

## 9. Related Work：可用于论文初稿的中文框架

### 9.1 表格建模与序列表征

树模型在多类表格任务中具有竞争力，但静态特征表示未必完整保留事件之间的关系。Grinsztajn 等的研究分析了表格模型的归纳偏置，其实验范围不能直接外推到所有大规模序列任务。[R14] TabFormer 将预训练引入多变量表格时间序列；FATA-Trans 进一步处理字段类型与时间信息。[R2][R5] 本研究关注这些序列表示在既有强特征之外的增量，而非仅用神经模型替换树模型。

### 9.2 无标签事件序列学习

CoLES 通过事件子序列构造自监督表示，并研究下游应用；NPPR 将下一事件预测与历史重建结合。[R3][R4] 推荐领域的 S3-Rec 也利用属性、项目和序列之间的相关性进行预训练。[R15] 这些工作说明预训练目标与编码结构有多种可选方式，因此本文需要同预算的统计、循环网络及对比学习对照，而非只与原始 XGBoost 比较。

### 9.3 工业行为模型与下游融合

PANTHER、nuFormer 与 PRAGMA 分别探索行为建模、画像或多源事件及下游适配。[R1][R7][R10] NVIDIA 示例展示了表示与 XGBoost 的工程融合。[R12] 本研究限定模型大小与可用输入，比较在既有特征较强、数据覆盖有限的条件下，紧凑表示是否仍提供额外信息；不宣称与这些大规模系统进行同条件性能竞赛。

### 9.4 增量不足与紧凑表示

TCT 报告了序列表示单独有预测力、与强人工特征合并却无明显收益的现象。[R9] 工业级 Transformer 比较研究也强调数据与计算条件的重要性。[R6] CARTA 研究紧凑单记录自监督表示，提供另一个需要区分的研究方向。[R11] 因而本文不仅测量表示单独的性能，还在完整人工基线下比较输出形式、训练偏置和成本，并以严格时间外评估检验增量。

以上是可改写的 related-work 逻辑骨架，不是对所有文献的综述。正式英文稿应结合最终实验，删除未实际相关的支线。

本次默认英文计算机/AI 期刊。以下是适配判断，不是录用概率或难度保证；未核实的年度 JCR/中科院分区不编造。

投稿前核实最新征稿范围、数据政策、版面费用和单位评价要求；不能把官网平均审稿时间当成自己论文的承诺。

## 11. 写作结构与首篇、后续工作的边界

建议结构：Introduction → Related Work → Problem and Temporal Protocol → Compact Representation Method → Experimental Setup → Results and Ablations → Efficiency and Limitations → Conclusion。

推荐主表/图：

1. 数据与时间切分表，含标签成熟及自然正例比例。
2. 模型参数和训练预算表。
3. 完整强基线上的 AP 主结果表。
4. embedding / surprise / 简单统计 / 残差方法消融表。
5. AP 增量随历史长度、参数或 GPU 小时变化的曲线。
6. 各时间段与历史覆盖分组结果。

先导实验可以用于动机，不能重复当作未见测试验证。文中需要说明私有数据不能公开的原因和可公开的复现材料，但不披露单位名称、标识或敏感业务细节。

第一篇应完整回答一个问题。后续可以研究新的问题，例如覆盖不全时的稳健性、在线更新与漂移、跨市场迁移或监督残差适配；这些需要新的方法和证据。不要把同一套实验人为切成几篇，也不要只把参数扩大当作下一篇贡献。[S6]

## 12. 下一步执行清单与继续/停止门槛

**阶段 A：不新增昂贵预训练。** 完成旧 Hybrid 的归因；读 R3、R4、R9；固定时间协议；从已有最新 encoder 导出 embedding（若架构允许），与 surprise 比较。

**阶段 B：最小模型研究。** 训练一个约 100万–300万参数的普通 Transformer；固定其输出协议；做简单统计、GRU、CoLES-style 对照。先在开发集筛查，再扩展多种子。

**阶段 C：一个增强假设。** 只测试残差式下一事件预测。若改善只在 NLL、不在 AP，记录失败并停止复杂化。身份消融有预算再做。

**阶段 D：发表证据。** 固定候选，完成真实时间外验证、公开序列数据复现、成本评估和不确定性报告，随后决定期刊与文章类型。

不预设必须提升多少百分比才可发表。小幅但稳定、跨时间可复现且成本低的改善，可能具有应用价值；单次微小改善且不确定性很大，则不能支持有效性主张。若全部无增益，需有充分的基线强度、输出方式和时间条件分析，才能支撑边界性论文；负结果不自动等于可发表贡献。
