# Local Word Banks

`guangdong_zhongkao_advanced.txt` is the active Word Practice bank. It is a
curated starter collection of higher-difficulty words commonly useful for
Guangdong junior-high-school entrance-exam reading, cloze, and writing.

Keep one lowercase English word per line. Add future word banks here and change
the path passed to `LessonFactory` in `ui/app.py` to select one.
